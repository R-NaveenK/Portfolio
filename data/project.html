Projects

Fruit Encyclopedia

Fruit Encyclopedia is an educational web project that provides organized information about various fruits and their benefits. Users can explore nutritional values, health benefits, and interesting facts in an easy-to-understand format. The project promotes healthy awareness while demonstrating web development fundamentals.

Skill Swap

Skill Swap is a community-based platform that connects people who want to learn new skills with those willing to teach them. It promotes peer-to-peer learning through knowledge sharing and collaboration. The project aims to make skill development more accessible, interactive, and community-driven.

Dimple

Dimple is an AI-powered mindfulness companion that helps users manage stress, overthinking, and emotional challenges. It provides supportive conversations and wellness guidance through an intelligent assistant. The project aims to make mental health support more accessible and engaging.

ACIDS - AI Cyber Defence System

ACIDS is an AI-powered industrial cyber defence and monitoring system designed to detect and respond to security threats. It utilizes a five-layer security architecture to enhance protection across critical systems. The project includes attack simulation demonstrations to showcase real-time threat detection and defence capabilities.
